# Node.js SharedArrayBuffer Bug

## Status: Root Cause Found, Fix In Progress

## Summary

The wasmer-js SDK fails to run in Node.js with the error:
```
TypeError: [object Int32Array] is not a shared typed array.
    at Atomics.waitAsync (<anonymous>)
```

## Root Cause

**The WASM linear memory is not declared as `shared`.**

The `wasm-bindgen-futures` crate uses `Atomics.waitAsync()` on the WASM linear memory buffer in `src/task/multithread.rs:177-179`:

```rust
let mem = wasm_bindgen::memory().unchecked_into::<js_sys::WebAssembly::Memory>();
let array = js_sys::Int32Array::new(&mem.buffer());
let result = Atomics::wait_async(&array, ...);
```

When inspecting the built WASM module, the memory is declared as:
```wasm
(memory $0 33)
```

But for `Atomics.waitAsync` to work, it must be:
```wasm
(memory $0 33 65536 shared)
```

## The Fix

The `.cargo/config.toml` is missing the `--shared-memory` linker flag:

**Current (broken):**
```toml
rustflags = '-Ctarget-feature=+atomics,+bulk-memory -Clink-args=--no-check-features --cfg=web_sys_unstable_apis'
```

**Required (fix):**
```toml
rustflags = [
  '-Ctarget-feature=+atomics,+bulk-memory,+mutable-globals',
  '-Clink-arg=--shared-memory',
  '-Clink-arg=--import-memory',
  '-Clink-arg=--export-memory',
  '-Clink-arg=--max-memory=4294967296',
  '-Clink-arg=--no-check-features',
  '--cfg=web_sys_unstable_apis',
]
```

## Current Blocker

After adding the linker flags, the WASM module correctly has shared memory:
```wasm
(import "env" "memory" (memory $mimport$0 33 65536 shared))
```

However, wasm-bindgen fails with:
```
error: failed to prepare module for threading
Caused by: failed to find `__wasm_init_tls`
```

This is a compatibility issue between the nightly Rust compiler version and wasm-bindgen. The `__wasm_init_tls` function is generated by Rust for thread-local storage initialization, but it's not being exported properly.

## Next Steps

1. Investigate wasm-bindgen version compatibility with current nightly Rust
2. May need to pin a specific nightly version that works with the wasm-bindgen version
3. Or update wasm-bindgen to a version compatible with the current nightly

## Environment

- Node.js v24.3.0
- wasmer-js from current main branch
- Rust nightly-2025-07-05
- wasm-bindgen 0.2.x
